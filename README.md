#1028Z

VEX V5 robot code for team 1028Z, written in C++ using VEXcode V5.

Overview

This repository contains the competition code for our VEX robot, including driver control and autonomous routines. Built on the standard VEXcode V5 competition template.

Hardware
6-motor drivetrain (front, middle, and back motors on each side)
Intake motor
V5 controller
Build

Standard VEXcode V5 project — open in VEXcode V5 and build/download to the brain, or build via the included makefile if using the VEX toolchain directly.
